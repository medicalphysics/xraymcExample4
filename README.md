# xraymcExample4

## About

This example demonstrates how to use the [XRayMClib](https://github.com/medicalphysics/XRayMClib) C++ library to simulate radiation transport in user defined geometry.

XrayMC have functionality to import tetrahedal and triangulated meshes to support arbitrary geometry. However sometimes users would like to implement custom scoring and/or custom geometry that cannot easily be represented by mesh geometry. This example demonstrates an implementation of a water filled tourus.
